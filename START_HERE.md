## Human Evidence Boundary

We do have human memorability evidence, but it has a specific scope.

Gold-standard and behavioral evidence already available:

- BOLD Moments human memorability labels are the ground truth for learning and
  evaluating the core `v_mem` direction.
- The local Prolific study has 41 raters, all passing attention checks. Study A
  found humans preferred the TRIBE-ranked best-of-N winner over the within-seed
  median variant 290/451 times, or 64.3%, with Wilson 95% CI [0.598, 0.686] and
  binomial p = 1.3e-9.

What that does and does not validate:

- It supports the broader claim that the TRIBE/BMD selector signal survives
  human contact.
- It does not by itself validate the newer V-JEPA-adjudicated selector pool.
- It does not by itself validate Arthur/Camilo's BO-generated videos.
- It does not prove delayed-recognition memorability.

The practical hierarchy is:

```text
human behavior / BMD labels
  > TRIBE/BMD proxy scores
  > BO, SVD, LoRA, and Modal compute workflows
```

The compute work should propose and stabilize candidate videos. Human evidence
is the reference standard.

## How To Refresh The Split Paper

The split paper is generated by:

```bash
uv run python scripts/build_neurips_selector_site.py
```

Only run this from an environment that has the local `data/reports/*` result
files available. In a clean worktree without the data lake, many numbers will
fall back to `n/a`.

When editing the paper text, update both:

- `scripts/build_neurips_selector_site.py`, which owns the generated template;
- `research_program/neurips_memorability_selector/main_selector_paper/paper.md`,
  so the current committed source stays readable before the next full rebuild.

## Current Next Move

Before new human trials, use compute-side work to stabilize candidate selection:

- replicated BO/TRIBE replay for stochastic generated videos;
- fixed-budget comparisons against random/Sobol/best-of-N;
- prompt-clustered ranking stability;
- seed-stratified tournament panels across matched prompts and budgets;
- then human validation only on candidates that survive the compute screen.

Do not frame proxy-only improvements as human memorability gains.
