# Overleaf Main Selector Paper

Upload the contents of this folder to a new Overleaf project:

- `main.tex`
- `appendix_protocol.tex`
- `references.bib`

Set `main.tex` as the main file. The project uses the standard Overleaf
`article` class, so it should compile without installing a conference template.

## Why not NeurIPS style yet?

This is currently a professor/IRB/research-review draft. It is intentionally
readable and protocol-forward. After the V-JEPA-augmented human validation is
complete, the same content can be moved into the official NeurIPS template and
trimmed to the page limit.

## What to send a professor

Send this Overleaf project plus the separate IRB packet:

- `../../irb/professor_irb_brief.md`
- `../../irb/irb_protocol_draft.md`
- `../../irb/consent_form_draft.md`
- `../../irb/prolific_launch_checklist.md`

The paper explains the scientific motivation. The IRB packet explains the human
subjects protocol, consent, risks, privacy, and launch steps.
