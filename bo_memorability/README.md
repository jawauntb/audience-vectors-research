# BO Memorability — Generating Memorable Videos with Bayesian Optimization

Optimizes the memorability of videos generated by **Stable Video Diffusion XT** using
**multi-objective Bayesian Optimization** (BoTorch / qLogNEHVI).

The main parameter is the *steering* coefficient (`alpha`) applied to the cortical
memorability vector `v_mem_clip` in the CLIP embedding space of SVD-XT.

## Assets not included in this repository

To keep this public repo lightweight and free of model weights, the following
are **not committed** and must be obtained separately before running:

| Asset | Path expected by the code | How to obtain |
|-------|---------------------------|---------------|
| Memorability direction | `artifacts/v_mem.npz` (20484-dim) | From the project maintainer (derived from TRIBE/fMRI) |
| TRIBE→CLIP adapter | `artifacts/tribe_clip_adapter.pt` (~88 MB) | From the project maintainer |
| Seed images | `seeds/fresh24_*.png` | From the project maintainer, or supply your own and update `seeds/prompts.json` |

Generated videos, run outputs (`outputs/`), and report PDFs are produced locally
and are git-ignored. The `results/run_3obj_trials.csv` table is included so the
3-objective run can be inspected/plotted without re-running the pipeline.

## Setup — local GPU (RTX)

This component lives in the `bo_memorability/` subfolder of the
`audience-vectors-research` repository and is self-contained.

```bash
# 1. Clone the repository and enter this component
git clone https://github.com/jawauntb/audience-vectors-research.git
cd audience-vectors-research/bo_memorability

# 2. Create a virtual environment
python -m venv .venv && source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Install TRIBE v2 (requires git)
pip install git+https://github.com/facebookresearch/tribev2.git@72399081ed3f1040c4d996cefb2864a4c46f5b8e

# 5. Place the assets that are not in the repo (see "Assets not included"):
#      artifacts/v_mem.npz, artifacts/tribe_clip_adapter.pt, seeds/fresh24_*.png
```

## How to run — 3-objective pipeline (recommended)

```bash
# Full run: 12 Sobol points + 10 BO iterations, batch=2
python scripts/main_3obj.py

# Main options:
#   --n-initial 12      initial Sobol points (default: 12)
#   --n-iterations 10   BO iterations after Sobol (default: 10)
#   --batch-size 2      candidates per iteration (default: 2)
#   --steps 25          SVD-XT frames (default: 25)
#   --no-resume         ignore checkpoint and start from scratch
#   --cpu-offload       enable cpu_offload on SVD-XT (for GPUs < 12 GB VRAM)
#   --device cuda       device (default: cuda)

# On startup, the script generates 8 reference videos (alpha=0) to calibrate
# the VideoQualityScorer and saves them to outputs/gpu_run_3obj/reference_videos/.
# On subsequent runs, it loads the saved centroid from quality_reference.npz.

# Results saved to:
#   outputs/gpu_run_3obj/all_results.json   ← scores of all evaluations
#   outputs/gpu_run_3obj/videos/            ← generated videos
#   outputs/gpu_run_3obj/pareto_front.png   ← 3-panel visualization

# Generate PDF report:
python scripts/generate_report.py
#   → outputs/bo_memorability_final_report.pdf
```

## Main parameters

| Parameter | Range | Description |
|-----------|-----------|-------------|
| `alpha` | [-10, 10] | Steering vector coefficient v_mem_clip in the CLIP embedding |
| `guidance_scale` | [1, 10] | CFG (classifier-free guidance) scale of SVD-XT |
| `seed_idx` | {0..15} | Seed image index (pool of 16, cycles if < 16 available) |

**BO objectives** — `main_3obj.py` (all maximized):

| Objective | Model | Description |
|----------|--------|-------------|
| TRIBE score | TRIBE v2 | `dot(TRIBE(video), v_mem)` — cortical memorability |
| CLIP score | CLIP ViT-H/14 | cosine similarity frames × prompt — visual fidelity |
| Quality score | R3D-18 (torchvision) | cosine sim to reference centroid (alpha=0) — visual quality |

## Technical notes

### Steering vector in SVD-XT
```python
# In svd_generator.py — monkey-patch of _encode_image:
def steered_encode(image, device, num_videos_per_prompt, do_cfg):
    emb = original_encode(...)   # (batch, 1, 1024)
    direction = v_mem_clip.to(emb.device, dtype=emb.dtype)
    return emb + alpha * direction.unsqueeze(0).unsqueeze(0)
```

### Memory — RTX 5080 (16 GB VRAM)
- SVD-XT loads directly onto the GPU (`cpu_offload=False` by default in `main_3obj.py`).
- Use `--cpu-offload` for GPUs with < 12 GB VRAM (e.g., T4, RTX 3080).

### VideoQualityScorer (R3D-18)
- Uses `torchvision.models.video.r3d_18` with the `fc` layer replaced by `nn.Identity()`.
- Extracts 512-dim features per video; score = cosine similarity to the centroid of 8 reference videos (alpha=0).
- Lightweight: does not require a large batch like classic FVD; works per-video.

### BoTorch — compatibility
- `botorch >= 0.12`: `HeteroskedasticSingleTaskGP` was removed.
  Replaced by `SingleTaskGP(train_Yvar=...)`.
- `qLogNoisyExpectedHypervolumeImprovement`: requires explicit `X_observed=train_x`.
